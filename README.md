# Atikur Rahaman Khan — Professional Portfolio

A complete static portfolio for the assignment. Open **index.html** in a modern browser (or use VS Code Live Server). No npm install is needed.

## Included
- Full-width, responsive navigation and hero with a professional photo
- Actual downloadable `assets/Atikur_Rahaman_Khan_Resume.pdf`
- Verified GitHub and email links
- About Me, skills grouped by category, education (BSc/HSC/SSC), and project experience
- Four real projects with image cards and dedicated pages under `projects/`
- Each project page contains its stack, description, verified links or explicit unavailable status, challenges and future improvements
- Contact section with email and phone field, plus a mailto contact form
- Keyboard-friendly menu and responsive layouts for mobile, tablet and desktop

## Before publishing / assignment submission
1. **Phone number:** add your real number in `site-config.js` (`phone: "+880..."`). The page currently displays “Available on request” because no number was provided.
2. **Live demos:** add actual deployed URLs to project pages once they exist. Unverified live links are deliberately disabled.
3. **GitHub links:** BookNook client folder is linked to the public repository. Other unpublished project repos explicitly say code is not public.
4. **Resume:** a downloadable resume PDF is included, built from known details. Review and replace it with your final personal resume if you have one; it intentionally does not list an unprovided phone number or false experience.
5. **Contact form:** opens the visitor's email application with a prepared message; it does NOT send email through a server. For backend sending, configure a form service or server.
6. Change `site-config.js` and the relevant contact/resume text if your public email changes.

## Files
`index.html` is the main page, `portfolio.html` is a compatibility copy for your previous filename, `CSS.css` contains the responsive styles, `index.js` contains menu/contact behavior, `site-config.js` contains personal contact config, and `projects/*.html` are individual case studies.

01 / OVERVIEW

About this project

TerraAnalog is a NASA Space Apps Challenge project exploring how Earth-based locations can be studied as analog environments for future Moon or Mars research. The work includes NASA satellite data processing and a planned discovery interface.

02 / FEATURES

What I worked on

  • Processed a NASA MODIS land-surface temperature data file
  • Applied scale factors and converted measured temperature units
  • Filtered data using quality-control flags
  • Explored sinusoidal projection and geographic coordinate conversion
03 / REFLECTION

Challenges

Working with real NASA HDF datasets, interpreting quality bits, and translating mapped coordinates into usable geographic positions required careful step-by-step validation.

04 / NEXT STEPS

Future improvements

Connect analysis to a polished discovery interface, expand geographic coverage, add evaluation criteria, and clearly explain data limitations.

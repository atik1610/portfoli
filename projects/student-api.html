Student API.

An API for practicing route parameters, queries, and data handling.

PythonFastAPIPydantic
01 / OVERVIEW

About this project

A small FastAPI learning project used to practice HTTP routes and working with student information. The focus is clarity rather than a large feature list.

02 / FEATURES

What I worked on

  • Basic API endpoints and response handling
  • Student lookups by path parameter
  • Filtering or sorting using query parameters
  • Error handling for invalid or missing data
03 / REFLECTION

Challenges

Learning the difference between path parameters and query parameters, and choosing the right response or error, were the main challenges.

04 / NEXT STEPS

Future improvements

Connect a persistent database, add CRUD operations, include authentication if needed, and create a small web interface.

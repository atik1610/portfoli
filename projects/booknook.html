BookNook.

A small online library with a Next.js frontend and a separate API.

Next.jsReactExpressMongoDB
01 / OVERVIEW

About this project

BookNook is a library web application that brings books, browsing, member accounts, and borrowing features into one digital experience. The project connects a modern frontend to an API and a database.

02 / FEATURES

What I worked on

  • Book discovery, categories, and a browsing experience
  • Account registration and login flows
  • Borrowing and returning journeys with database records
  • A responsive interface with a dedicated frontend and server
03 / REFLECTION

Challenges

Connecting the frontend, authentication layer, API, and MongoDB reliably was an important part of this project. Local development, deployment configuration, and database connectivity required careful debugging.

04 / NEXT STEPS

Future improvements

Continue testing the complete borrowing flow in a deployed environment, polish accessibility, refine load states, and make deployment more predictable.
